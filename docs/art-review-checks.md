# Art Review Checks (Ship Designs)

What Ship Designs checks before accepting Arty's floor plans. A plan that fails any check is sent back.

- **One tile per system — Decided (2026-10-26, heromedel):** no system takes more than one tile.
- **EVA and EVB Docks by an airlock — Decided (2026-10-26, heromedel):** a floor plan with an EVA or EVB Dock that is
  not next to an airlock is not accepted.
- **Every powered system wired — Decided (2026-10-23):** on conduit ships, conduits reach the room of every system
  that needs power. Mounts need none: conduits feed systems, not mounts (GDD 5H, Proposed 2026-10-27).
- **Real plans show the real ship — Decided (2026-10-23):** damage and other demonstrations go in labelled mockups,
  never in the actual plans.
- **Nothing blocks a tile — Decided (2026-10-25):** crew can stand on every tile, consoles included.
