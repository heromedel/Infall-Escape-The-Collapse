# Mecha Light Attack Frame

The current Mecha Light Attack Frame is in [`pixel-redo/`](pixel-redo/): the sleek battle-cross hull, its floor
plans, pixel weapons and armed previews, accepted by Ship Designs.

The earlier vector frame (old Mecha colours, replaced on 2026-10-25), its review sheets and its build tools were
removed on 2026-10-26; they are in git history.
