# Infall: Escape The Collapse

A design-stage project: we are writing a game design document, not building the game yet.

- Follow `docs/game-project-standards.md`: standard rules (workflow, labelling of plans/steps/questions,
  branch rules), elegant code principles, and the designer's game design philosophy.
- `docs/gdd.html` is the game design document. Points are lettered per section (e.g. 2A) and tagged
  Decided / Likely / Proposed / Open. Undiscussed ideas go in `docs/ideas.md`.
- A shared, co-editable copy of the GDD exists at https://claude.ai/artifact/DNRJEFZkzS4zBL1nPHoLmX. Don't keep
  it in sync automatically; when the user asks to see the GDD, ask whether they want the git version or the
  editable one, and update the editable one only then.
- The user's original idea document is a Google Doc (snapshot in `docs/original-design-idea.md`); others,
  e.g. Nina, may add ideas there.

## About the designer

- Mechanics should feel like FTL (treated as a genre) unless a decision says otherwise (GDD 1C).
- Loves optional settings. A feature that departs from FTL can be a toggle so players can make the game more
  like FTL. Settings are written with the default first, e.g. `Multi Target Lasers: On > Off`.
